## Pubblicazione (GitHub Pages)

Il sito è pubblicato tramite **GitHub Pages** dal branch principale:

1. Carica i file nella root del repository (mantieni il nome `index.html`).
2. Settings → Pages → Source: *Deploy from a branch* → branch `main` / cartella `/ (root)`.
3. Il sito è raggiungibile all'indirizzo indicato nelle impostazioni di Pages.

Nessuna build necessaria: il sito è HTML/CSS/JS statico.
